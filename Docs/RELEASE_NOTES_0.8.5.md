# OKVideoMac 0.8.5（Build 138）Release Notes

- 新增本机崩溃捕获与恢复页面。下次启动先处理过滤后的诊断报告，再初始化业务、播放历史和运行时；原配置与历史继续使用。
- 过滤报告最多保存 3 份、保留 7 天。设置页提供诊断共享控制；报告不包含播放内容、配置、凭据、日志或原始崩溃文件。
- 本次正式包未配置远程崩溃上传端点，不会发送崩溃报告。已集成的发送、重试与撤回路径在独立验收环境验证；启用服务需要后续明确配置。
- 退出和更新安装先完成播放器、Node、Android 与诊断清理，减少进程或上传工作残留。
- 新建窗口保留 SwiftUI 原生场景创建动作，支持关闭所有浏览窗口后重新打开；恢复阶段仍阻止该动作。
- Android SDK 可执行文件检查增加 2 秒截止、有限清理和明确的超时状态。超时保留 SDK/AVD 选择，可重新检查，不误报为架构不支持。
- 补齐静态诊断 SDK 的许可证、源码归档、SBOM 与隐私资源容器，并验证最终 App/helper dSYM UUID。

macOS 14.8.9 / arm64 的自动化、播放与暂停睡眠/唤醒功能验收已经完成。用户指定范围外的 macOS 12、AirPods/蓝牙及两个未提供的外部 Node Contract B 样本未新增实机覆盖。USB 后台维护唤醒发生过，连续深睡和耗电验收未完成。

此前一次临时副本启动在 20 秒内未看到屏幕窗口；后续九次全新目录/身份测试均出现窗口，但原始日志被覆盖，根因仍未证实，不宣称这一现象已修复。没有新增零泄漏或所有第三方依赖支持源码行解析的保证。

正式分发沿用 Developer ID、Apple 公证、staple、Gatekeeper、签名更新 feed 及源码/许可证校验流程。构建时快照与公开 tag 保持不可变；结果见最终发布验证记录。
